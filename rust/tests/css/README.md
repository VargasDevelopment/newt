# Shared CSS validation

The real parser is newt-core::css, not a second standalone implementation.
The mandatory css_gate.py family checks all276 frozen case identities, complete
command-aware response grammar, independent field expectations, the exact
original C++ output,15 freshly compiling actual-core/transport mutants, malformed
request rejections and both exact nonempty runtime-borrowed RV32exports.

Frozen Css.cpp, ZipCatalog.cpp and miniz implement the C++ oracle; the adapter
only supplies controlled sources/storage. All original hashes/notices remain.
Byte syntax, C definedness and typed/arena capacity differences are explicit
in CONTRACT.md. Source READ traces, statuses, hashes, declarations and rule
order are compared. Crashes, timeouts, malformed replies and compiler errors
never count as semantic control detections.

The C --abi record is HOST layout only. No raw Rust POD is serialized and no
BookCatalog cache compatibility, target layout, firmware, runtime resource,
hardware or performance acceptance is claimed. Those remain future work.
