# Security

## Report a vulnerability privately

Use GitHub's private vulnerability reporting: open this repository's
**Security** tab and choose **Report a vulnerability**. Only the owner sees
the report.

Never report a vulnerability in a public issue, pull request or discussion.

Please include what is affected, how to reproduce it, and the Newt version
and build (Settings, Diagnostics, About). Never include your Wi-Fi password,
other credentials or a copyrighted book.

## Supported versions

Only the latest release gets security fixes. Newt updates itself over Wi-Fi
or from the card ([README](README.md#install)).

## Scope

The Newt firmware, its update and install paths (including the install page
in `installer/`), and the tools in this repository. Problems in FreeInk,
ESP-IDF, the Arduino-ESP32 core or another third-party component belong
with that project; tell us too if Newt is affected.
