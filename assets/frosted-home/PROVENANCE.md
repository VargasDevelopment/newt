# Frosted Home resources

Owner-approved Home B is preserved in `source/`, including its exact selected scene, raster, artwork, font files and full licenses. `source/freeze-manifest.json` retains upstream handoff SHA-256 values. The canonical PNG SHA-256 is `54e14ba8918c78fb679704289cf71fe776b211184db8e5191419070c71f4457c`.

The supplied Inter regular/bold fonts are unmodified, licensed under SIL OFL 1.1 (`source/assets/Inter-OFL.txt`). Their actual PostScript identities are Inter18pt-Regular and Inter18pt-Bold. No other system face substitutes during import. Generated NewtHomeAtlas bitmap coverage is a project-specific raster derivative; the original font files retain their upstream identity and notices. Lexend files remain unmodified reference-compositor dependencies. Reader typography continues to use the existing NewtReadingAtlas, not this Home atlas.

The former C++ import tools (`tools/frosted-font.swift` and `tools/make-frosted-home.py`, retired in NEWT-90) exported exact approved whole labels and bounded eight-phase glyphs from the preserved local inputs using Python and macOS Swift/CoreText. Generic glyph coverage is packed to four levels; exact approved labels retain the compositor's 8-bit mask before final composition. Runtime variable strings use the same Inter faces and measured advances/kerning, but their subpixel coverage is quantized and is not claimed to match arbitrary CoreText strings pixel-for-pixel. Supported glyphs are printable ASCII, middle dot, right apostrophe and ellipsis; other glyphs visibly use `?` in this same face. Long fields fit/truncate within their assigned column.

`resources.json.zlib` is bounded, inert build-time provenance data. The firmware's Home atlas (`rust/ui-canvas/src/data.rs`) and Frosted Home base raster and labels (`rust/system-ui/src/data.rs`) are pinned Rust literals converted from those verified outputs; Home links immutable static raster/metric arrays and loads neither TTF nor PNG nor zlib, allocates no font cache and stores no full 2-bit framebuffer. The separate EPUB reader retains its own archive/parser implementation.

The haze background is precomputed and static. The original image is a design fixture; firmware does not show The Secret Garden cover or fictional clock/battery/progress for the authored Small Lantern sample. Artwork is the unchanged owner-provided/approved asset handoff; Newt brand artwork (`newt-brand-reference.png` and its derivatives) is outside the MIT license (see `README.md` "Name and logo"). No additional reuse or external licensing rights are asserted for fixture artwork beyond this project handoff.

## Stage Home backdrop (issue #29)

`stage-backdrop.bin` (104,544 bytes, SHA-256 `8f64b34bf1e1d055572a9589b97b18df026df1989c79e098489c576c7428f913`) is generated, not drawn. `tools/make-stage-backdrop.py` derives it only from the frozen, owner-approved `source/assets/newt-brand-reference.png`, whose identity it checks against `source/freeze-manifest.json` (through `tools/brand_source.py`). It follows the Stage spec recipe (`design/home-refresh/SPEC.md` blob `f7f2b65ded3345d5b0f2d925eed49cba4fc5c75b` and `design/home-refresh/tools/build.py` blob `7601cecfd6e3b42c16a12feb70821ff8044170bd`, on `design/home-visual-refresh`): the mascot crop (214,296 600x640) area-averaged to 532x567 at (-2,44), a Gaussian σ22 blur, a 30% veil with a tone-128 floor, 150 px edge frost to 92 levels, the title and header clearings, serpentine Floyd-Steinberg to four tones, then the approved Home wordmark crop (200,951 628x210) multiplied on top, area-averaged to 86x28 at (28,12) as the spec mockup does (not Frosted Home's high-quality scaling). It is a project derivative of the same approved brand artwork (outside MIT per `README.md` "Name and logo"); no third-party art, font or network input. Blur and dithering use exact integer or correctly rounded IEEE arithmetic, so `python3 tools/make-stage-backdrop.py --check` reproduces and verifies the bytes on any host for both tracked copies: `assets/frosted-home/stage-backdrop.bin` and `rust/stage-home/assets/frosted-home/stage-backdrop.bin`. Layout: the LSB then MSB selector plane of one 528x792 frame, MSB-first rows. Host previews and tests read it, and the Rust firmware build (`newt.bin`) links `rust/stage-home/assets/frosted-home/stage-backdrop.bin` via `rust/stage-home/src/lib.rs`. The backdrop occupies flash and adds no framebuffer or heap copy.
